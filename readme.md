## About DriveSphere

DriveSphere is an intuitive car rental platform designed to simplify the process of renting cars. It serves three types of users, each with their own dashboard:

1. **User (Client)**: Browse and book cars for rental.
2. **Admin**: Manage users, cars, and bookings on the platform.
3. **Car Owner**: List their cars for rent and manage availability.

The platform aims to provide a seamless experience for all users with a focus on functionality, usability, and scalability.

---

## Features

- **Three Dashboards**: Separate dashboards for each user type (User, Admin, Car Owner) to cater to their specific needs.
- **Car Management**: Car Owners can add and update car listings.
- **Booking System**: Users can search for cars, view availability, and book them.
- **Admin Control**: Admins can manage user roles, bookings, and the overall system.

---

## Technologies Used

- **Frontend**: React, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB

## How to Run the Website Code

step-1 : Unzip the code

step-2 : Navigate to the "car_rental" directory

step-3 : Navigate to the "server" folder and run the command
(backend server - 8000) - cd ./server - npm install - npm start

step-4 : Navigate to the "client" folder and run the command
(frontend server - 5173) - cd ./client - npm install - npm run dev

step-5 : our website is live on port-5173
